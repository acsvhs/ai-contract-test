# AI Contract Test v0.1.0-alpha.1

`v0.1.0-alpha.1` is the first public preview of AI Contract Test. It provides a local-first,
provider-neutral Java core for deterministic contract checks against HTTP and OpenAI-compatible
chat-completions endpoints.

## Status

This is a **pre-release**. Contract format version 1 is strict, but Java APIs and configuration may
change before `v0.1.0`. Do not treat this release as a compliance, privacy or security guarantee.

## Requirements and compatibility

- Java 21 or newer.
- Linux or Windows; both are validated in GitHub Actions.
- Maven Wrapper for building from source.
- No API key or Internet service is required by the default test suite or Spring example.

## Release assets

- `ai-contract-cli-0.1.0-alpha.1.jar`: executable CLI with its runtime dependencies.
- `ai-contract-cli-0.1.0-alpha.1.jar.sha256`: SHA-256 checksum for the CLI JAR.
- GitHub-generated source archives for the exact release tag.

The Maven modules are not published to Maven Central. Run `./mvnw install` from the source tree to
use `io.github.acsvhs:ai-contract-maven-plugin:0.1.0-alpha.1` or the JUnit integration locally.

## Quick verification

```bash
java -jar ai-contract-cli-0.1.0-alpha.1.jar --version
java -jar ai-contract-cli-0.1.0-alpha.1.jar --help
```

## Included

- YAML parsing, strict schema validation and safe variable interpolation.
- Generic HTTP and OpenAI-compatible chat-completions targets.
- Tool-call and token normalization without a provider SDK.
- Deterministic assertions, including user-configured token cost limits.
- CLI, Maven and JUnit 5 integrations.
- Console, JSON and JUnit XML reports.
- Explicit `live`, `record` and `replay` modes with sanitized cassettes.
- Central redaction and configurable local secret/PII pattern checks.

## Known limitations

- Phase 4 remains incomplete: there is no HTML reporter, tag/case filtering or recursive directory
  execution yet.
- Only non-streaming `/v1/chat/completions` requests are supported by the OpenAI-compatible adapter.
- Cassettes contain full sanitized response bodies. Review them manually before forcing them into
  version control; redaction can have false negatives.
- Cost estimates are only available when contracts supply their own current pricing values.
- Execution is sequential and the project remains experimental.

## Validation

The release commit is validated with:

```bash
./mvnw --batch-mode --no-transfer-progress clean verify
java -jar ai-contract-cli/target/ai-contract-cli-0.1.0-alpha.1.jar --version
java -jar ai-contract-cli/target/ai-contract-cli-0.1.0-alpha.1.jar --help
```

Formatting, Checkstyle, the core JaCoCo threshold, local HTTP integration tests, offline replay tests,
Maven/JUnit integrations and the Spring Boot consumer all run as part of `verify`. The public CI
matrix is available under [GitHub Actions](https://github.com/acsvhs/ai-contract-test/actions).
The Maven build uses a fixed output timestamp and the executable JAR is rebuilt twice before upload
to confirm byte-for-byte reproducibility.
